# Інтелектуальна система керування роботизованою рукою із застосуванням комп'ютерного зору

![Фото маніпулятора](imageshardware.jpg)
Зовнішній вигляд розробленого маніпулятора

![Скриншот інтерфейсу](imagessoftware.png)
Інтерфейс програми під час відстеження кисті

Цей репозиторій містить програмне та апаратне забезпечення для безконтактного жестового керування 3D-друкованою антропоморфною роботизованою рукою (16 ступенів свободи). Система працює в «режимі тіні», відтворюючи рухи руки оператора в реальному часі з використанням звичайної веб-камери.

## Основні можливості
 Безмаркерний трекінг Відстеження 21 ключової точки кисті за допомогою MediaPipe.
 Двоступенева EMA-фільтрація Програмне (Python) та апаратне (ESP32S3) згладжування для усунення тремтіння сервоприводів.
 Автономна логіка Підтримка лівої та правої руки з безпечним переходом великого пальця через кінцевий автомат.
 Висока швидкодія Обробка відеопотоку 30-35 FPS із затримкою 60-80 мс.

## Апаратне забезпечення
 Мікроконтролер ESP32S3.
 ШІМ-драйвер 16-канальний PCA9685 (I2C).
 Виконавчі механізми Сервоприводи SG90 та MG90S (16 шт).
 Живлення Окреме джерело 5V, 15A+ для сервоприводів; роздільне живлення для логіки ESP32S3.

## Програмне забезпечення та інсталяція
Проєкт складається з обчислювального ядра на Python та прошивки для ESP32S3.

### 1. Прошивка ESP32S3
Завантажте код з `srcesp32_firmware` у плату ESP32S3 через Arduino IDE (потрібна бібліотека `Adafruit_PWMServoDriver`).

### 2. Запуск Python-ядра
Переконайтеся, що встановлено Python 3.10+.
```bash
# Встановлення залежностей
pip install -r srcpython_cvrequirements.txt

# Запуск
python srcpython_cvmain.py
